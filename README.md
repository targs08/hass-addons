# Home Assistant Add-ons: targs08

Personal collection of Home Assistant add-ons.

## Installation

1. In Home Assistant go to **Settings** → **Add-ons** → **Add-on Store**.
2. Open the three-dot menu in the top right and choose **Repositories**.
3. Add `https://github.com/targs08/hass-addons` and click **Add**.
4. The add-ons below appear in the store after the list refreshes.

[![Add repository to your Home Assistant instance][repo-badge]][repo-url]

## Add-ons

| Add-on | Description |
| ------ | ----------- |
| [PXE Proxy](./pxe-proxy) | Proxy DHCP server for PXE network booting, based on dnsmasq. |
| [Netboot.xyz (fork)](./netboot-xyz) | Fork of FaserF's netboot.xyz add-on with a `tftp_server_ip` option. |
